# Customer Churn Analysis & Customer Intelligence

## 📌 Project Overview

Customer churn is an important business problem because losing existing customers can directly impact revenue and long-term growth.

This project analyzes customer and subscription data to understand customer behavior, identify churn patterns, and generate actionable business insights.

The analysis includes data extraction, data cleaning, transformation, exploratory data analysis, SQL-based analysis, and data visualization using Python and SQLite.

## 🎯 Project Objectives

- Analyze customer and subscription data
- Identify customer churn patterns
- Understand customer behavior and subscription trends
- Handle missing and inconsistent data
- Perform data cleaning and transformation
- Analyze subscription plans and contract types
- Study monthly charges and customer lifetime value (CLTV)
- Analyze cancellation reasons
- Generate actionable business insights

## 🔍 Analysis Performed

### 1. Data Extraction

Data was extracted from a SQLite database using SQL queries and loaded into Pandas DataFrames for further analysis.

### 2. Data Cleaning

The data preparation process includes:

- Missing value identification
- Handling missing country information
- Date format conversion
- Data consistency checks
- Duplicate and data-quality checks
- Preparing datasets for analysis

### 3. Exploratory Data Analysis

The project explores:

- Customer demographics
- Subscription patterns
- Plan and contract types
- Monthly charges
- Customer lifetime value
- Cancellation behavior
- Churn-related patterns

### 4. Data Visualization

Visualizations are used to identify patterns and communicate important findings related to customer behavior and churn.
